Multi-Tenant React Application — Detailed Breakdown & Developer Instructions
Project Status

The core infrastructure is 100% complete. This includes the Redux store setup, React Router implementation, Role-Based Access Control (RBAC), Layout shells, and the global Ant Design theme. The next step is for team members to build out their specific pages.

1. Detailed File & Folder Architecture

Here is an explanation of every file in the src/ directory and what it does.

/src/index.js CORE

The absolute entry point of the React app. It imports the global CSS first (so CSS variables are available everywhere) and mounts the <App /> component to the DOM.

/src/App.js CORE

The root component. It wraps the entire application in three critical layers:
1. <Provider store={store}> (Makes Redux state available).
2. <ConfigProvider theme={antdTheme}> (Applies our custom Cream & Sage colors to all Ant Design components).
3. <AppRouter /> (Handles all page navigation).

/src/app/store.js STATE

The configuration file for Redux Toolkit. It combines all reducers. Currently, it holds the authReducer. If the app needs more global state later (e.g., tenant data), it will be added here.

/src/features/auth/authSlice.js STATE

Manages all authentication data. It stores the user object, JWT token, role, and isAuthenticated boolean. It exports the setCredentials action which the login/signup pages must call upon success.

/src/router/routes.constants.js ROUTING

A dictionary of all URL paths (e.g., ROUTES.LOGIN = "/login"). Rule: Never type raw string URLs in your components; always import them from this file.

/src/router/AppRouter.jsx ROUTING

Defines which component loads for which URL. It groups routes logically: Public Auth routes, Protected User routes, Protected Admin routes, etc. It assigns the correct Layout wrapper to each group.

/src/router/ProtectedRoute.jsx ROUTING

A security gatekeeper component. Before loading an admin dashboard, this component checks Redux. If the user isn't logged in, they go to /login. If they don't have the right role, they go to /unauthorized.

/src/assets/styles/global.css STYLING

Defines the global CSS variables (colors, fonts, spacing). It imports the "Plus Jakarta Sans" font and applies a CSS reset so the app looks identical across all browsers.

/src/theme/tokens.js & antdTheme.js STYLING

tokens.js exports our colors as JavaScript objects. antdTheme.js maps those colors to Ant Design's token system so buttons and inputs automatically match our theme.

/src/layouts/* UI SHELLS

The "frames" of the app. AuthLayout provides the centered card background. AdminLayout, UserLayout, and SuperAdminLayout provide the sidebars and top navigation bars. Team members' pages render inside these layouts.
